# Source Map

- `wentor-research-plugins`：`symbolic-computation-guide`、`numerical-methods-guide`、`linear-algebra-applications`、`oeis-api`。
- `kdense-scientific-skills`：`skills/sympy` 的精确算术、assumptions、solver selection 和 `lambdify` 性能模式。
- 项目现场能力探针：`scripts/check_math_tools.py`，只报告真实安装且通过最小行为测试的工具。
- SageMath conda 安装边界：SageMath 官方 installation guide 的 conda-forge 方案；项目脚本不自行分发 Miniforge。
- Rust 安装边界：Rust 官方 rustup；Rust 不属于数学证据 verifier，未纳入 capability PASS 计数。
- 未吸收：Mathematica、Magma 等商业许可能力，以及没有当前消费者的第二套形式化证明栈。
