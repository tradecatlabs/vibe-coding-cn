# Runtime Records

这里放代理运行记录和临时材料。任务包统一放在 `governance/tasks/`，长期价值内容应沉淀到 `evidence/`。

```text
runtime/
├── README.md
├── runs/README.md   # 可丢弃的运行回执，不是项目真相源
└── tmp/README.md    # 可丢弃的临时材料，不得被长期文档引用
```

`runs/` 与 `tmp/` 只保留目录契约；实际运行产物按项目忽略规则管理，不作为完成证据提交。
