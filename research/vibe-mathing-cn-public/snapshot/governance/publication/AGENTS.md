# Public publication assets

This directory records the public documentation contract.

- Claims must be supported by public files, schemas, fixtures, tests, or fixed metadata.
- Metamodel claims must preserve PLFB as the single conceptual root, PWTSJ as F05, OSPS as F04, reference-only Body composition, and explicit non-implementation boundaries.
- This is not a Problem, Attempt, Result, or Solution source of truth.
- Do not add private research outputs, credentials, runtime/session data, or unadmitted mathematical candidates.
- Run the README/GEO and public-boundary checks after changes.
