# Task Package Checklists

## TP-01

- [x] 核心、邻接、背景三层范围明确。
- [x] 关键词、语言、provider、停止条件和排除项明确。
- Verify: 人工审阅 `SEARCH_PROTOCOL.md`。
- Gate: 范围、证据等级、停止条件和排除项完整，且不宣称穷尽全网。

## TP-02

- [x] 来源账本覆盖原生术语、公开案例、工具、论文、批评和失败。
- [x] 每项包含来源层级、产物、实践启示和限制。
- Verify: URL 抽查与交叉引用审阅。
- Gate: 核心事实有原始来源，失败和限制没有被成功叙事覆盖。

## TP-03

- [x] 综合报告给出实践谱系、案例矩阵、最小工作流和验证阶梯。
- [x] 项目建议与当前 `Problem → Attempt → Result` 操作模型一致。
- Verify: 每条强结论可回指来源 ID。
- Gate: 生成、数学正确性、kernel check、陈述忠实性和新颖性分离。

## TP-04

- [ ] 固定一个 informal generate-referee-repair 案例做产物复核。
- [ ] 固定一个 Lean vibe-proving 案例做本地构建与 axiom audit。
- [ ] 建立按月或重大事件触发的增量检索回合。
- Verify: 版本化运行记录与新增账本条目。
- Gate: 固定 commit、工具链、真实命令和可重算证据后才能标记完成。
