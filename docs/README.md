## 使用方式

先选任务：第一次实践走入门教程；理解、判断、构建、验证与研究转化查功法；核对外部事实查研究域。
需要给 AI 上下文时，提供 [根 AGENTS](../AGENTS.md)、[docs AGENTS](AGENTS.md)，再给当前功法文集或具体任务材料。
