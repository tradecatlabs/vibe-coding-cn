# 功法体系

## 字多不看

- 方法论、哲学、思维模型、工程准则与操作方法统一从这里选用，不再按旧目录分别找。
- 先看要解决的问题，再选择功法；同一方法在不同任务中的效果和品级不能直接比较。
- 阅读正文用下方文集；逐条身份、来源和已有初评查看[功法总表](../../metadata/gongfa/catalog.md)或[Excel](../../metadata/gongfa/catalog.xlsx)。
- 文集可以包含多条功法和配套解释，不等于一门独立功法；迁移或篇幅不产生新身份与品级。
- 内容分解释型、准则型、方法型；不可分复合保留上位类型。已有初评不是正式效果评级。
- [本体与品级](cultivation-ontology-taxonomy.md#功法本体与品级)解释类型、内容版本和天地玄黄四阶十二级。

## 使用方式

1. 写清当前任务的目标、约束和验收，再从功能导航选文集。
2. 区分解释、准则和方法，阅读适用条件、限制和反证，不把原文断言当已证明事实。
3. 需要逐条选用或核对初评时查功法总表；登记与候选、初评与正式结果分别判断。
4. 原始研究材料仍在[研究域](../../research/README.md)，运行能力仍在[Skills](../../skills/README.md)。

## 正文

正文已拆分到上述独立文集。文集是组织与阅读单位；一门功法的身份仍由 ID＋内容版本确定。
